# FWSController

Automation controller for the Firework Shows product.

## Requirements
- CopyPaste plugin

## Permission
```bash
oxide.grant user PLAYERNAME fwscontroller.use
```

## Commands

### Spawn Shows
```txt
/fws1 - /fws21
```

Example:
```txt
/fws6
```

### Delete Shows
```txt
/fws1del - /fws21del
```

Example:
```txt
/fws6del
```

### Height Adjustment
```txt
/fws6 height 3
```

### Help
```txt
/fwsinfo
```

## How It Works
1. Spawn a show using a command
2. The plugin pastes the structure automatically
3. You receive an RF transmitter
4. Use the transmitter to start the synchronized firework show
5. The show cleans itself up automatically

## Notes
- Only one of each show can be active at a time
- Look at the ground/surface when spawning a show
- Inventory space is required for the RF transmitter
- This plugin was made using AI and was only created to make it easier for you to use my product.
